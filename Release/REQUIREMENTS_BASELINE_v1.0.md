# PinChat 需求基线 v1.0

- 状态：已确认并冻结（Frozen）
- 冻结时间：2026-09-15（Asia/Shanghai）
- 适用版本：PinChat macOS MVP 初版
- 变更规则：本文件冻结后不得修改、覆盖或删除。后续的新想法、范围调整或版本需求只能写入新的独立文档，不得回写本基线。

## 1. 产品定位

PinChat 是一个“插件形态”的 macOS 原生 Codex 置顶小窗。技术上允许使用一个轻量原生后台进程承载系统级浮窗，但产品不得表现为另一套聊天主应用。

PinChat 必须满足：

- 没有自建聊天主页面。
- 没有自建历史会话侧边栏或历史会话菜单。
- 不复制 Codex 的完整界面。
- 不在 Dock 中显示常规应用图标。
- 小窗只作为本机 Codex 的快捷输入与输出入口。
- 当前会话的完整承载和管理归属于 Codex。

## 2. Codex 集成与账号

- 使用本机 Codex App Server 与真实 Codex 会话通信。
- 使用官方 ChatGPT 登录流程，不读取浏览器 Cookie，不保存用户密码。
- 不要求用户提供 OpenAI API Key。
- 使用用户自己的 Free、Plus、Pro 或适用的工作区 Codex 使用额度。
- 对话必须创建为真实、可由 Codex 打开的本地 Codex 任务，而不是 PinChat 自行模拟的聊天记录。
- 小窗右上角“在 Codex 中打开”按钮必须打开当前同一个 Codex 会话，不得打开 PinChat 自建页面。
- 小窗内不提供历史会话入口；历史会话统一由 Codex 主应用管理。

## 3. Codex 行为一致性

- PinChat 不得注入自定义“友好助手”、ChatGPT 或其他替代人格提示词。
- PinChat 不得强制覆盖本机 Codex 的默认模型、人格或推理强度。
- 新会话应继承本机 Codex 当前有效的默认模型、人格和推理配置。
- 普通文本问答应尽可能保持与本机 Codex 一致的回答行为。
- 小窗不承担完整工具执行和审批界面；需要文件操作、终端执行或授权确认时，应在 Codex 主应用中继续当前会话。

## 4. 打开方式

必须同时提供两种入口：

1. 全局快捷键 `⌥ Space` 打开或收起小窗。
2. 点击常驻悬浮按钮打开或收起小窗。

悬浮按钮必须：

- 默认显示在其他普通应用上方。
- 可在设置中关闭或重新开启。
- 支持拖动。
- 拖动结束后自动贴靠屏幕左右边缘。
- 保存位置。
- 支持多显示器。

## 5. 小窗行为

- 小窗默认置顶，并允许用户关闭或重新开启置顶。
- 在普通桌面应用和普通 macOS 全屏 Space 中均可显示和使用。
- 支持拖动和缩放。
- 保存窗口位置和尺寸。
- 显示器连接、断开或布局变化后，窗口与悬浮按钮应保持在可见区域。
- 支持收起，不因切换到其他应用而自动消失。
- 系统锁屏、登录界面、系统安全权限窗口及受保护 DRM 画面不属于可覆盖范围。

## 6. 对话功能

- 新建对话。
- 输入并发送纯文本问题。
- 流式显示 Codex 回答。
- 生成期间可停止回答。
- 显示当前会话内容。
- 必要时同步当前真实 Codex 会话的新增文本内容。
- 不在小窗中显示历史会话列表或历史会话切换入口。

## 7. 回答排版与字体风格

- 回答区域的整体阅读体验应与 Codex 桌面应用相似，而不是使用普通网页聊天气泡或另一套强烈视觉风格。
- 助手回答以清晰、克制的正文排版为主，减少厚重气泡感；用户输入与助手回答仍需容易区分。
- 正文字体、字号、字重、行高、段落宽度和段落间距应贴近 Codex，并优先使用 macOS 原生系统字体体系。
- 中文正文使用系统中文字体回退；英文与界面文字使用系统字体；代码和等宽内容使用系统等宽字体。
- 正确显示 Codex 常用的 Markdown 结构，包括标题、正文段落、有序与无序列表、粗体、斜体、行内代码、代码块、引用和链接。
- 代码块应具有与 Codex 相似的等宽字体、背景、内边距和圆角，并支持文本选择与复制；长代码不得破坏小窗整体布局。
- 流式回答过程中排版应保持稳定，不应频繁跳动、丢失 Markdown 层级或改变字体。
- 浅色和深色模式下均使用接近 Codex 的中性背景、正文、次要文字、分隔线和代码块配色，并保证可读性。
- 视觉目标是“相似且协调”，不要求复制 Codex 的私有资源或逐像素复刻。

## 8. 设置与系统体验

- 提供菜单栏入口。
- 提供基础设置页，至少包含：默认置顶、悬浮按钮开关、快捷键说明、ChatGPT 账号和计划状态。
- 提供登录失败、本地服务不可用、生成失败、快捷键冲突、打开 Codex 失败和本地保存失败等必要错误提示。
- 跟随 macOS 浅色与深色外观。
- 支持多显示器。
- 应用作为轻量后台伴随组件运行。

## 9. 初版交付物

- 完整、可维护的 Swift / SwiftUI macOS 原生源码。
- 可使用 Xcode 打开、构建和调试的工程。
- 可在当前 Mac 上实际启动和使用的 `PinChat.app`。
- 本机构建脚本。
- 与实现风险相匹配的自动测试和实际运行验证。
- 安装、首次登录、运行、构建和已知边界说明。

## 10. 本轮不包含

- 其他 AI 服务或第三方模型 API。
- 文件、图片或其他附件。
- 语音输入或语音输出。
- 写作模板。
- Apple Developer ID 正式签名与公证。
- App Store 上架。

## 11. 最终验收定义

用户能够在 macOS 上运行交付的 `PinChat.app`，通过官方 ChatGPT 登录和本机 Codex App Server 使用自己的计划额度；能够在普通应用及普通全屏 Space 中通过 `⌥ Space` 或常驻悬浮按钮唤出置顶小窗，完成真实 Codex 文本对话，并将当前同一个会话交回 Codex 主应用继续。小窗不得包含独立聊天主页面或历史会话入口，也不得塑造与本机 Codex 不同的人格；回答的字体、Markdown 层级、间距、代码样式及浅深色阅读体验应与 Codex 桌面应用协调一致。
