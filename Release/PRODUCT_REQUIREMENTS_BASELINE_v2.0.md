# PinChat 产品需求基线 v2.0（冻结）

状态：已确认、实施中、冻结  
确认日期：2026-09-15  
适用范围：PinChat 桌宠式交互流程重构

## 1. 冻结规则

本文件记录用户确认的 PinChat v2.0 产品需求。完成 SHA-256 校验并设为只读后不得原地修改；后续新增、删除或变更需求必须新建更高版本基线，并保留 v1.0、v1.1 与本文件。

## 2. 产品定位

- PinChat 是 macOS 原生 Codex 伴随组件，不制作独立聊天主应用。
- 对话由本机 Codex App Server 执行，使用用户自己的 ChatGPT Free、Plus、Pro 或工作区额度，不接 API Key。
- 新任务继承本机 Codex 的默认模型、推理强度和人格。
- PinChat 内不提供历史任务列表；完整任务管理仍在 Codex 主应用中进行。
- PinChat 不修改 Codex 官方桌宠或 Codex 应用设置；用户可自行隐藏官方桌宠，避免界面重叠。

## 3. 核心交互流程

### V2-01 Codex 风格桌宠入口

- 以高保真蓝色 Codex 机器人作为常驻桌宠入口，支持待机、工作、完成、失败和拖动反馈。
- 桌宠位于所有普通桌面及全屏 Space 上方，可在设置中关闭。
- 桌宠可拖动并约束在当前屏幕可见范围内；松手后保留位置。
- 优先从本机 Codex 缓存加载官方图集；没有缓存时从 OpenAI 官方静态资源地址下载并缓存在 PinChat 自己的缓存目录中。
- 官方素材不可用时显示 PinChat 内置的 Codex 风格矢量后备形象，不能阻断提问。

### V2-02 迷你输入条

- 点击桌宠旁的铅笔按钮，显示贴近桌宠的玻璃质感迷你输入条并自动聚焦。
- 输入并发送后，等效于向本机 Codex 创建或继续一个真实请求。
- 输入条提供发送和停止按钮；未登录时提供明确的登录或重试入口。
- 输入条方向根据桌宠周围可用屏幕空间自动选择，不能溢出屏幕。

### V2-03 状态卡

- 请求发出后，桌宠下方或上方显示贴附的状态卡。
- 生成期间显示“正在思考”状态；结束后显示任务标题和回答摘要；失败时显示错误状态。
- 完成卡提供三个动作：`↗` 在 Codex 中打开当前任务、`✓` 确认完成并准备新任务、`↓/↑` 展开或折叠完整回答。
- 确认完成不会删除 Codex 任务，只清理 PinChat 当前展示状态并准备新任务。

### V2-04 回答面板

- `↓/↑` 根据桌宠位置与屏幕空间，智能向下或向上展开完整回答。
- 回答面板使用接近 Codex 的字体、间距、Markdown、代码块与用户气泡样式。
- 回答面板支持拖动、缩放、关闭，以及在同一任务内继续提问。
- 初次展开时回答面板吸附桌宠；拖动桌宠时，仍吸附的输入条、状态卡和回答面板同步跟随。
- 用户单独拖动回答面板后解除吸附；再次折叠并展开时恢复智能吸附布局。
- 面板必须被约束在当前显示器可见范围内，并支持浅色、深色模式。

### V2-05 Codex 交接

- 点击 `↗` 时，只有在当前回答完成或停止后才可交接。
- PinChat 先停止同步、取消线程订阅并终止自己启动的 App Server 子进程，再打开 `codex://threads/<thread-id>`。
- Codex 打开后进入同一任务，保留已有问答并可立即继续对话，不出现线程被其他客户端占用的提示。
- 成功交接后 PinChat 切换为新空白任务；再次使用时按需重启服务。

## 4. 窗口与快捷键

- 桌宠、输入条、状态卡和回答面板采用独立透明或材质 `NSPanel`，组成一个视觉连续的浮动控件。
- 所有浮动窗口支持普通 macOS 全屏 Space，且不会因为其他应用失去焦点而消失。
- 默认全局快捷键改为 `⌥⇧Space`，避免与 Codex 官方桌宠的 `⌥Space` 冲突；快捷键等效于打开或关闭迷你输入条。
- 菜单栏保留显示/隐藏入口、在 Codex 中打开、设置和退出。

## 5. 本轮不做

- 不修改或注入 Codex 官方应用 UI。
- 不提供历史任务列表、独立主页面或另一套账号系统。
- 不接入其他 AI API；列入未来候选项。
- 不实现语音按钮，因为当前公开 App Server 能力没有提供官方桌宠语音接口。
- 不执行需要 Codex 主应用审批的高风险工具操作；PinChat 继续使用只读沙箱与 never 审批策略。

- 通过全部 Swift 测试、Release 构建、Info.plist 校验、ad-hoc 签名校验与 v1.0/v1.1/v2.0 冻结需求哈希校验。
- 在真实 macOS 窗口中完成视觉检查：桌宠透明背景、输入条、思考卡、完成卡、向上/向下回答面板、拖动与缩放。
- 完成一次真实 Codex 请求、继续追问和线程交接验证。
