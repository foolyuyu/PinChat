# PinChat 3.17 回答窗切换输入框需求基线（已锁定）

锁定日期：2026-09-19（Asia/Shanghai）

## 需求

1. 点击完整回答窗右上角的小笔时，不得继续保留空白回答窗。
2. 回答窗必须以用户实际点击小笔的屏幕坐标为目标，向该点缩小并淡出。
3. 收拢动画完成前保留原回答内容，不得提前切换为空白新会话。
4. 回答窗完全消失后，再创建新的 Codex 对话，并从桌宠处展开紧凑小输入框。
5. 整个切换必须串行完成，禁止回答窗和小输入框同时闪现；快速重复点击不得重复触发。
6. 右上角 `×` 仍是普通关闭回答窗；小笔是“收起当前回答并开始新提问”的专用入口。

## 验收标准

1. 收拢终点中心与点击坐标一致，目标尺寸为 28×28 pt。
2. 收拢动画时长为 0.24 秒，使用缓入缓出和透明度过渡。
3. 动画过程中不会把缩小后的临时尺寸保存为回答窗下次打开尺寸。
4. 动画完成后回答窗恢复原始尺寸供下次使用，小输入框正常获得焦点。
