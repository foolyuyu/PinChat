# PinChat v3.14 输入条展开与注视顺序需求基线（锁定稿）

锁定日期：2026-09-18（Asia/Shanghai）

本文件记录输入条展开速度及桌宠“先低头、再转向插入光标”的修正。v1.0 至 v3.13 其他冻结需求继续有效；本文件不得回改既有基线，只允许后续版本追加。

## 1. 输入条展开

- 输入条横向展开时间由 v3.13 的 0.24 秒进一步调整为 0.30 秒。
- 收回时间继续保持 0.22 秒，不修改两侧向中心收拢的几何效果。

## 2. 官方注视顺序

- 输入条刚开始展开、真实文字插入光标尚未稳定时，桌宠先看向输入条的中心位置。
- 输入条吸附在桌宠下方时，该预设目标表现为先低头；若因屏幕空间不足改为向上展开，则自然看向实际输入条方向。
- 等待约 0.14 秒让输入布局建立后，文本框获得焦点；一旦取得真实插入光标屏幕坐标，立即切换为 v3.13 已锁定的 16 向低头光标追踪。
- 不恢复 v3.12 的逐格转圈式过渡。

## 3. 范围边界

- 统一 Codex 任务队列、简单对话自动展开、持续灯泡提醒及“回答窗只由 × 关闭”已写入确认稿，但本版仍不实现该流程。

## 4. 验收标准

- 展开速度比 v3.13 略慢且不拖沓。
- 动作顺序稳定表现为先看向输入条，再转向真实插入光标。
- 关闭输入条后继续从官方慢速待机首帧恢复，无额外跳动。
- 自动测试、Debug/Release 构建、签名及 v1.0 至 v3.14 全部冻结需求校验通过。
