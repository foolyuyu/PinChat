# PinChat v3.10 点击外部自动收回需求基线（锁定稿）

锁定日期：2026-09-18（Asia/Shanghai）

本文件记录输入小窗的失焦收回与退场动画要求。v1.0 至 v3.9 其他冻结需求继续有效；本文件不得回改既有基线，只允许后续版本追加。

## 1. 点击外部自动收回

- 输入小窗展开后，用户点击桌面或其他应用时必须自动收回，无需再次点击桌宠或按快捷键。
- 输入小窗内部操作不得触发收回。
- PinChat 主动打开的附件菜单、文件选择器和照片选择器不得因为窗口焦点变化而误收回输入小窗。
- 从 Finder 按住文件或文件夹连续拖入输入小窗并放下时，不得把起始于其他应用的拖动误判为外部点击；输入小窗保持展开并正常接收附件。
- 自动收回只作用于尚未发送的紧凑输入小窗，不得停止正在运行的任务，也不得擅自关闭已展开的回答窗口。

## 2. 中心收拢动画

- 输入小窗从左右两端同时向自身水平中心收拢，中心点和垂直位置保持不变。
- 收拢过程中允许同步淡出，但水平压缩必须清晰可见，不能表现为瞬间消失。
- 点击桌宠、按 `Esc` 或再次使用快捷键收回输入小窗时，复用同一中心收拢动画。
- 动画结束后恢复完整窗口尺寸，确保下次展开不会继承压缩后的宽度或透明度。
- 快速连续收回与重新展开不得被旧动画的完成回调再次隐藏。

## 3. 验收标准

- 展开输入小窗并点击桌面或其他应用，小窗自动执行中心收拢动画并消失。
- 使用输入区、附件入口和系统文件选择器时，小窗保持可用。
- 从 Finder 将文件连续拖入输入框时窗口不收回，附件成功进入待发送队列。
- `Esc`、桌宠点击和快捷键关闭均呈现相同的左右向中心收拢效果。
- 连续快速打开、关闭、再打开后，小窗仍保持正确位置、完整宽度和正常透明度。
- 自动测试、Debug/Release 构建、签名及 v1.0 至 v3.10 全部冻结需求校验通过。
