# PinChat v3.7 完成任务确认回收需求基线（锁定稿）

锁定日期：2026-09-18（Asia/Shanghai）

本文件记录 PinChat v3.7 的增量需求。v1.0 至 v3.6 已冻结需求继续有效；本文件不得回改既有基线，只允许后续版本追加。

## 1. 统一语义

- 所有完成状态中的 `✓` 均表示“我已看完，立即回收这条状态”。
- PinChat 当前问答完成卡的 `✓` 继续立即关闭当前状态框并结束这组小窗对话。
- Codex 桌面任务悬停列表中，每条已完成任务左侧的 `✓` 必须成为可点击按钮，不再只是静态图标。

## 2. 桌面任务确认

- 点击某一条已完成任务的 `✓`，只确认并移除该任务。
- 其他正在思考、等待操作、失败、停止或已完成任务不得受到影响。
- 列表仍有其他任务时，状态框继续显示并按剩余内容调整高度。
- 最后一条可见任务被确认后，整个桌面任务状态框立即执行既有收起动画。
- 确认操作不得打开 Codex、不得创建新对话、不得停止或修改桌面端任务。

## 3. 与查看规则的区别

- 普通悬停查看仍遵守 v3.6 规则：已展示的完成项在完成满 30 秒后才从后续列表中隐藏。
- 主动点击 `✓` 属于明确确认，不受 30 秒最短展示时间限制，必须立即隐藏。
- 主动确认结果必须持久化；后续轮询或重启应用不得让同一条完成回执重新出现。
- 同一 Codex 任务将来产生新的完成回执时，应作为新结果正常展示。

## 4. 验收标准

- 当前 PinChat 问答完成后点击 `✓`，状态框立即回收。
- 桌面任务列表中点击任一已完成任务的 `✓`，目标行立即消失，其他行保持。
- 点击最后一项的 `✓` 后，任务卡完整收起且无完成状态闪帧。
- 轮询同步期间点击 `✓`，已确认项目不会短暂闪回。
- 自动测试、Debug/Release 构建、签名及 v1.0 至 v3.7 全部冻结需求校验通过。
