# PinChat v3.11 任务卡悬停表面需求基线（锁定稿）

锁定日期：2026-09-18（Asia/Shanghai）

本文件记录桌面任务卡悬停视觉层与卡片本体的统一要求。v1.0 至 v3.10 其他冻结需求继续有效；本文件不得回改既有基线，只允许后续版本追加。

## 1. 视觉问题定义

- 本轮问题不是桌宠与任务卡之间的距离，也不得修改两者的位置关系或窗口层级。
- 旧版单任务悬停层上下各缩进 5 pt、圆角小于外卡片，因此看起来像一张没有与卡片本体重合的内层阴影卡。
- 悬停反馈必须遵循任务卡本体的完整轮廓，不得出现错位、双层卡片或独立漂浮的深色矩形。

## 2. 单任务与多任务悬停

- 只有一项任务时，行悬停层必须覆盖整张任务卡，包括原顶部和底部 5 pt 留白，并使用外卡片相同的 18 pt 圆角裁切。
- 多任务时，首行、末行和中间行分别占用各自完整区域；所有行统一由外卡片 18 pt 轮廓裁切。
- 行内反馈保持克制，不使用额外投影或缩小的圆角卡片。
- 已完成任务的确认按钮继续与对应行内容垂直对齐，不能因首末行扩展而偏移。

## 3. 整卡质感

- 鼠标进入任务卡时，整张卡片沿原轮廓增加轻微的白色提亮、弱强调色反射和细边缘光。
- 整卡悬停层必须与玻璃卡片使用完全相同的尺寸和 18 pt 圆角。
- 悬停进入与离开使用约 0.14 秒淡变；开启“减少动态效果”时取消该动画。
- 对话状态卡、输入条和完整回答窗口不受本轮修改影响。

## 4. 验收标准

- 单任务卡任意位置悬停时只呈现一张完整卡片，不再看见上下缩进的内层矩形。
- 多任务卡逐行悬停时，高亮区域连续铺满该行，首末行自然贴合外轮廓。
- 任务卡整体边缘光与卡片本体像素级重合，进出动画无跳动。
- 桌宠与卡片保持 v3.10 原位置和层级。
- 自动测试、Debug/Release 构建、签名及 v1.0 至 v3.11 全部冻结需求校验通过。
