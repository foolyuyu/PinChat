# Changelog

PinChat is currently a development preview. Until the first public release,
entries summarize meaningful development milestones rather than a stable API.

## Unreleased

- Prepare the repository for public testing with CI, security, privacy,
  architecture, contribution, and roadmap documentation.
- Clarify the independent community-project status and MIT source license.

## 0.3.17

- Added the answer-window-to-composer transition centered on the toolbar click.
- Kept the newly opened composer focused and protected it from the originating
  click's outside-dismiss event.
- Stabilized floating panel appearance across window transitions.
- Refined multi-task separators and restored visible actions for active tasks.
- Unified PinChat and Codex task status presentation.
- Added official-style caret tracking, idle timing, and completion feedback.

Detailed frozen requirements and verification evidence are stored in
[`Release/`](Release/).
